\begin{abstract}
Web-RAG systems serve all users the same top-$k$ evidence, ignoring the preference signals in a user's search history. We add a bilinear score intervention to a frozen cross-encoder reranker: a single trainable matrix $A \in \mathbb{R}^{768 \times 16}$ couples the document representation $h(q,d)$ with a user vector $u$ via $h(q,d)^\top A\, u$, at 12{,}288 trainable parameters. On 200k AOL sessions, this raises session-level nDCG@10 from $0.459$ to $0.543$ ($\Delta{=}{+}0.084$, paired bootstrap 95\% CI $[+0.034, +0.131]$), and the gain is stable across three seeds (mean $+0.081$, std $0.008$). Three ablations isolate what matters. (i) A user-only bias $w^\top u$ with no document interaction contributes nothing; the bilinear term is the active mechanism. (ii) A random user vector is not significant, so the bilinear term exploits genuine user signal rather than memorizing session identity. (iii) Against two equally minimal alternatives that also couple $h$ and $u$, the bilinear form is Pareto-optimal: it beats concatenation-plus-linear and matches FiLM at half the parameters. The user-vector dimension saturates at 8. The practical takeaway: for session-conditioned evidence reranking, a compact bilinear interaction matters more than how the user vector is built.

\keywords{Web information retrieval \and Retrieval-augmented generation \and Personalized search \and Cross-encoder reranking \and Click-log learning}
\end{abstract}
